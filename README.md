# SO101 OneClick Installer

One-click installer for SO101 + LeRobot on Windows WSL2.

Designed for education, robotics, and AI teaching.

---

## Features

✅ One-click installation

✅ WSL2 support

✅ Ubuntu 24 / 26

✅ Locked package versions

✅ Automatic dependency checking

✅ USB permission configuration

✅ Camera detection

✅ Automatic repair

✅ Chinese network optimization

---

## Quick Start

```bash
git clone https://github.com/yourname/SO101-OneClick-Installer.git

cd SO101-OneClick-Installer

chmod +x install.sh

./install.sh
```
